Geração de Relatório Consolidado

Monte o conjunto de documentos a anexar ao parecer técnico. Você pode gerar um único PDF unificado (capa + módulos em sequência) ou usar o modo sequencial (N PDFs separados que você combina depois).

01

Capa institucional

Identificação do parecer e do responsável técnico. Os campos abaixo são preenchidos automaticamente quando há dados sincronizados nos módulos.

02

Módulos a incluir no relatório

Selecione quais análises comporão o documento final. Cada módulo será impresso como anexo separado.

03

Exportar

Escolha o formato: PDF unificado abre uma nova janela com o documento consolidado (capa + módulos) e dispara automaticamente o diálogo de impressão — escolha "Salvar como PDF" para obter um arquivo único. O modo sequencial gera N PDFs separados que você combina depois com Acrobat/PDFsam/qpdf. Permita popups deste site para usar o PDF unificado.
